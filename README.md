# handgemacht-marketplace

Public [Claude Code](https://docs.claude.com/en/docs/claude-code) plugin
marketplace for **HAVI** — capture visual annotations from any web page and
route them to your coding agent for fast, context-rich fixes.

## Install

```
/plugin marketplace add handgemacht-ai/handgemacht-marketplace
/plugin install havi@handgemacht
```

Then follow the guided setup at <https://havi.handgemacht.ai/try>.

## Plugins

| Plugin | Description |
| --- | --- |
| `havi` | HAVI annotation platform — review and resolve visual annotations captured from the browser. |
